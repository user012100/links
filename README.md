# Gossip

This project is a curated collection of images, videos, audio, texts, and links exploring how gossip operates in both historical and contemporary contexts. The collection looks at gossip on a structural, interpersonal, and digital level: how it circulates between people, how it creates social bonds, and how platforms amplify and reshape it.

The archive was collaboratively assembled on **Are.na**, used as a CMS. I then designed and built a custom website using the Are.na API, translating the collection into a dynamic and exploratory website.
